# UE Project RAG 更新日志

## 0.1.1 - 2026-09-04

- 将索引从全量删除重建改为按文件内容哈希增量更新，报告新增、修改和删除文件数量。
- 增加索引版本、文件数量和最后更新时间等状态元数据，并用原子锁避免并发重建。
- 检索默认使用 AND，可通过 `mode` 选择 AND/OR，并支持 `phrase` 精确短语检索。
- MCP 启动参数增加 `-u`，减少 stdio 缓冲导致的连接等待。
- 补充增量更新、检索模式、短语检索和索引状态测试。

## 0.1.0 - 2026-08-06

- 首次发布本地 Unreal Engine 项目检索 MCP 服务。
- 索引源码、INI 配置、文档和可选的资产导出元数据。
- 排除常见构建目录和敏感文件模式。
- 提供索引、检索、读取结果和状态查询工具。
- 使用本地结构化与全文检索，不会把项目内容发送给 embedding 或聊天 API。
